# Blood Bank Real-Time Donor Matching System

## Problem Statement

Blood banks struggle to connect emergency blood requests with eligible donors quickly because donor information is often outdated and availability is unknown.

## Project Overview

This project is a real-time blood donor matching system that helps connect emergency blood requests with eligible and available blood donors.

The system allows users to register as donors, update their availability, and receive blood requests. Patients or blood banks can create emergency requests and find suitable donors based on blood group and location.

## Main Goal

The main goal of this project is to reduce the time required to find eligible blood donors during emergency situations.

## Key Features

- Donor registration and login
- Donor profile management
- Blood group management
- Donor availability tracking
- Emergency blood requests
- Real-time donor matching
- Location-based donor search
- Blood request tracking
- Notifications for eligible donors
- Admin/Blood Bank management

## Users

### Donor
- Register and login
- Add blood group and personal details
- Update availability
- View blood requests
- Respond to emergency requests

### Patient / Requester
- Create emergency blood requests
- Specify required blood group
- Enter location and required units
- Track request status

### Blood Bank / Admin
- Manage donors
- Manage blood requests
- Verify donor information
- Monitor blood availability
- Match suitable donors with requests

## How It Works

1. Donor registers on the system.
2. Donor provides blood group, location, and availability.
3. Patient or blood bank creates a blood request.
4. System searches for suitable available donors.
5. Matching donors are identified.
6. Donors receive the request.
7. Donor responds to the request.
8. Blood bank or requester tracks the request status.
